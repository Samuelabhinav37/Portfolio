## The problem

An ad blocker sees every page you visit. That makes it one of the most trusted pieces of software in a browser. Many popular ones also run servers, collect usage data or sell "acceptable ads" placements. I wanted a blocker whose privacy story is simple enough to check: nothing about you leaves the browser.

Moat removes ads, trackers, cookie banners and scam pop-ups before a page finishes loading. The only network requests it makes are for signed filter updates, and those carry nothing about the person using it.

## How it works

Moat is built on Manifest V3's `declarativeNetRequest`. Instead of inspecting each request in JavaScript, it hands the browser a compiled rule set and lets the browser's own engine do the blocking. That keeps pages fast and means Moat never needs to see request contents.

- **Network blocking.** About 314,000 filter entries from 11 AdGuard lists, plus three independent sources for redundancy, packed into about 72,000 browser rules.
- **Pop-up firewall.** Hijacked new-tab pop-ups and redirects, like fake prizes and fake virus warnings, are closed the moment they open. A background safety net catches anything that slips past.
- **Cosmetic filtering.** Hides the ad boxes and cookie banners that network blocking can't reach. It supports procedural rules such as `:has-text` that a plain stylesheet can't express.
- **Signed daily updates.** Filter fixes and fresh phishing, malware and scam domain lists are checked against a key built into the extension before they are used.

Everything else is opt-in: fingerprinting resistance, leaked-password warnings using HaveIBeenPwned's k-anonymity range API, and uncloaking trackers that hide behind a site's own subdomain.

Most of these were found by driving the extension against real sites, not by reading about their markup. The sites involved change their markup often enough that static assumptions don't hold.

## Privacy, checked

Blocking needs no server. There is no account, no analytics and no crash reporting. The one online component is a small inbox for problem reports a person chooses to send, and it keeps no logs. Every permission Moat asks for is listed in the README next to the reason it's needed. Several are inert unless an opt-in feature is switched on.

## What's next

Moat builds for Chrome, Firefox and Firefox for Android from one codebase, with 126 unit test files run in CI on every push. The next step is the Chrome Web Store and Firefox Add-ons listings. Until then it installs from source in a few minutes.
