## The problem

Inbox cleanup tools usually want to read everything. Many of them send your mail to their own servers to do it. That trade is backwards for a security tool. The data needed to sort a promotions folder, or to spot a fake bank, is mostly in the headers.

Cluster works from metadata only: sender, subject, date, size, read and starred state, and a handful of headers. Everything runs in the browser under the person's own OAuth sign-in. Nothing is stored server-side.

Cleanup covers the usual chores. Cluster sorts mail into labels by what it is (one-time codes, receipts, shipping) or who sent it. It can push a real Gmail filter so new mail gets sorted on arrival, even with the browser closed. It also unsubscribes through verified one-click requests, and lets you build rules with a dry run that shows exactly what would change. Every destructive action is behind a confirm. Starred mail is always skipped, and the action log offers Undo wherever the provider supports it.

## Detecting impersonation from headers

The Phishing screen runs header-only checks. They use data already fetched for cleanup, so they need no new OAuth scope and make no network calls of their own.

Flagged senders appear in their own section, never mixed into the cleanup view. The response is deliberately manual: "Label as suspicious" files the current messages under a Possible Phishing label and archives them. It never deletes, and it never creates a standing filter. A lookalike domain today isn't proof about whatever that sender sends next.

<DetectionOpportunity>
  Gmail already returns the <code>Authentication-Results</code> header with metadata requests once you ask for it. That one header turns DMARC, SPF and DKIM verdicts into a free phishing signal for every sender, with no body access at all.
</DetectionOpportunity>

## The one exception

Deep scan is the only feature that reads a message body. It is per-message, opt-in and Gmail-only. It fetches the HTML to compare a link's visible text with where it actually goes. It is labelled as the exception everywhere it appears, so the metadata-only promise stays true by default.

## What's not finished

Gmail supports everything. Outlook covers most features through Microsoft Graph, but snooze and Deep scan remain Gmail-only. Cluster handles one account per provider for now. The next milestone is a full live test against real mailboxes before any store release.
