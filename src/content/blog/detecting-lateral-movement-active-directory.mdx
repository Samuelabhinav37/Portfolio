Lateral movement is where most intrusions are won or lost. The initial foothold is noisy in theory and quiet in practice, but the moment an attacker starts authenticating to other hosts, they leave a trail in Windows event logs that a well-tuned detection stack can catch.

## The event IDs that matter

Start with 4624 logon type 3 from workstation to workstation. Workstations rarely talk to each other directly in a healthy environment, so peer-to-peer SMB authentication is one of the highest-signal, lowest-noise detections you can write.

Layer in 4648 (explicit credential use) and 4672 (special privileges assigned) and you can build a scoring model that separates an admin doing their job from an attacker sweeping the subnet with <Mitre id="T1021" /> techniques.

## Honeytokens as tripwires

A disabled service account with an attractive name and an SPN set is free to deploy and nearly impossible for an attacker to resist. Any Kerberos ticket request against it (4769) is a confirmed detection, not a maybe.
